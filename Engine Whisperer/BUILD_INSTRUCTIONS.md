# Инструкции по сборке Engine Whisperer

## 🚀 Быстрый старт

### Требования:
- **Xcode**: 15.0+ (рекомендуется 15.1+)
- **iOS**: 15.0+ (оптимизировано для iOS 18+)
- **Swift**: 5.9+
- **Устройство**: iPhone 12+ или iPad с микрофоном
- **Память**: Минимум 2GB RAM
- **Процессор**: A12 Bionic или новее

### Шаги сборки:

1. **Откройте проект в Xcode**
   ```bash
   open "Engine Whisperer.xcodeproj"
   ```

2. **Выберите устройство**
   - iPhone 12 или новее (рекомендуется)
   - iOS 15.0+ (оптимизировано для iOS 18+)

3. **Очистите проект** (если нужно)
   - Product → Clean Build Folder (⌘+Shift+K)

4. **Соберите проект**
   - Product → Build (⌘+B)

5. **Запустите приложение**
   - Product → Run (⌘+R)
