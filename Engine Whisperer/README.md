# Engine Whisperer 🏎️

**Дипломный проект - iOS приложение для диагностики автомобильных двигателей**

## 📱 Описание

Engine Whisperer - это инновационное iOS приложение, которое использует анализ звука для диагностики состояния автомобильного двигателя. Приложение записывает звук работающего двигателя через микрофон устройства и анализирует его с помощью продвинутых алгоритмов обработки сигналов.

## 🚀 Основные возможности

### ✅ Реализованные функции:
- **Реальная запись звука** с микрофона устройства
- **FFT анализ** для частотного анализа звука
- **Визуализация звуковых волн** в реальном времени
- **Определение состояния двигателя** (норма/предупреждение/критично)
- **Измерение уровня шума** в децибелах
- **Оценка RPM** (оборотов двигателя)
- **Частотный анализатор** для детального анализа
- **Современный дизайн** в стиле Ferrari
- **Правильная обработка разрешений** микрофона

### 🔧 Технические особенности:
- **AVAudioEngine** для записи звука
- **Accelerate framework** для FFT анализа
- **SwiftUI** для современного интерфейса
- **Combine** для реактивного программирования
- **Окно Ханна** для уменьшения спектральных искажений
- **RMS анализ** для точного измерения уровня звука

## 🎯 Алгоритмы анализа

### 1. **Обработка звука**
- Запись с частотой дискретизации 44.1 кГц
- Применение окна Ханна для уменьшения искажений
- RMS (Root Mean Square) анализ для уровня звука

### 2. **FFT анализ**
- Быстрое преобразование Фурье для частотного анализа
- Поиск пиковых частот
- Анализ доминирующих частот

### 3. **Диагностика двигателя**
- **Критический уровень**: > -20 dB (возможна детонация)
- **Предупреждение**: -40 до -20 dB (аномалии)
- **Норма**: < -40 dB (стабильная работа)

## 🚀 Запуск проекта

### Быстрый старт:
1. Откройте `Engine Whisperer.xcodeproj` в Xcode 15.0+
2. Выберите симулятор iPhone 15 или реальное устройство
3. Нажмите ⌘+R для запуска
4. Разрешите доступ к микрофону при первом запуске

### Для iPhone 12 и выше:
1. Убедитесь, что Xcode обновлен до версии 15.0+
2. Выберите устройство iPhone 12 или новее
3. Установите iOS 15.0+ на устройство
4. Запустите приложение

## 📱 Требования

- **iOS**: 15.0+ (оптимизировано для iOS 18+)
- **Xcode**: 15.0+
- **Swift**: 5.9+
- **Устройство**: iPhone 12+ или iPad с микрофоном
- **Память**: Минимум 2GB RAM
- **Процессор**: A12 Bionic или новее
